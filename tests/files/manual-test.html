Manual Test Page

Use this page to test breakpoint coexistence between VS Code and DevTools. 

From a VS Code notebook cell, try:

// Simple call (steppable in both VS Code and DevTools)
add(3, 4)

// Multi-step function (set breakpoints on individual lines in VS Code)
runDemo()

// Object inspection (useful for variable/scope pane testing)
inspect({ x: 1, y: [2, 3], z: { nested: true } })
